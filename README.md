# Farouk Yusuf — Data Analyst Portfolio

This is a **plain static website**. There is no build step and Python is not required to run it.

## Everyday workflow

1. Open this folder in VS Code.
2. Edit `index.html`, the files in `case-studies/`, and the CSS/JS in `assets/`.
3. Right-click `index.html` and choose **Open with Live Server**.
4. Save a file and Live Server will normally refresh the browser automatically.

## Main files

- `index.html` — homepage
- `assets/css/home.css` — homepage design
- `assets/css/tokens.css` — site-wide colours and design variables
- `assets/css/layout.css` — shared navigation
- `assets/css/case-study.css` — case-study layouts
- `case-studies/*.html` — the six case studies
- `assets/illustrations/` — lightweight industry illustrations used on the homepage cards
- `assets/images/` — detailed case-study charts and visuals
- `assets/docs/Farouk_Yusuf_Resume_Data_Analyst.pdf` — résumé linked from the homepage

## About the old Python builder

The previous Python generator has been preserved in `archive/python-builder/` only as a reference. **You do not need to run it.** The live HTML files are now the source of truth.
