The deliverable · interactive prototype

Alderwick priority dashboard

A working version of the four-page supervisory dashboard from the case study. Start with all 12 firms, open one to see its staffing trend and quality ratings, open an audit to see the exact score breakdown and findings, then land on the specific overdue task and the person who owns it.

Built with the same synthetic dataset as the case study — every figure here reconciles with it. This browser prototype stands in for the Power BI report; the scoring model and data model are described on the case-study page. Source data is produced by a seeded Python generator (CSVs alongside it).

Synthetic-data and independence disclaimer

Alderwick Reporting Council is fictional. Every audit firm, audited entity, engagement, inspection, finding and remediation record was generated for this portfolio. The problem and terminology are informed by public Financial Reporting Council material, but this project was not commissioned, reviewed or endorsed by the FRC. No result describes or permits an inference about any real firm or audit.
